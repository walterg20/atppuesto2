# Comando: /build-feature

## Descripción
Dispara la fase de desarrollo en paralelo delegando tareas al `implementador-backend` y al `implementador-frontend`.

## Instrucciones de Ejecución
1. Verificar que la especificación en `openspec/features/[modulo]/` esté completa.
2. Notificar a `implementador-backend` para generar entidades JPA, repositorios y servicios Spring Boot.
3. Notificar a `implementador-frontend` para construir los componentes Angular Standalone.
4. Actualizar el progreso en `tasks.md`.
